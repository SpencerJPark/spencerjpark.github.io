# spencerjpark.github.io

Portfolio site for Spencer Park, project manager for swag and promotional products, events, fulfillment, video, and web.

Plain HTML and CSS, no build step. GitHub Pages serves `index.html` from the root of the `main` branch.

## Files
- `index.html`: the whole site
- `assets/`: posters and the Stitch Punk GIF
- `Spencer_Park_Resume.pdf`: linked from the Contact section

## Updating
Edit `index.html`, commit, and push. Pages republishes within a minute or two.
